# Flexible Non-Linear Regression Examples

Methods capable of capturing complex non-linear patterns in data, for when linear approaches prove insufficient.

- [30-margin-svm.md](/examples/regression/flexible/30-margin-svm.md) - `reg_svm`: support vector regression with margin-based fitting.
- [40-neural-mlp.md](/examples/regression/flexible/40-neural-mlp.md) - `reg_mlp`: multilayer perceptron for nonlinear numeric prediction.
