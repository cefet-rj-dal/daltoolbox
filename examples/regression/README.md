# Regression Examples

This section organizes regression examples as a progression of modeling ideas, one subfolder per family, so each folder maps 1:1 to a slide deck.

If you are learning numeric prediction in `daltoolbox`, read the subfolders in order. The early notebooks help build intuition before the later ones introduce stronger nonlinear models and hyperparameter search.

- [Linear Regression](linear/README.md) - [d051_regression_linear.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d051_regression_linear.pdf)
- [Beyond Linear Regression](beyond-linear/README.md) - [d052_regression_beyond-linear.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d052_regression_beyond-linear.pdf)
- [Ensemble Regression](ensemble/README.md) - [d053_regression_ensemble.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d053_regression_ensemble.pdf)
- [Flexible Non-Linear Regression](flexible/README.md) - [d054_regression_flexible.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d054_regression_flexible.pdf)
- [Model Selection](model-selection/README.md) - [d055_regression_model-selection.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d055_regression_model-selection.pdf)
