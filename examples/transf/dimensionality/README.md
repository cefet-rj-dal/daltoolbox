# Dimensionality Reduction and Heuristics Examples

These examples help the reader decide how many dimensions or cut points may be enough for a problem.

> Slide deck: `d039-dimension-reduction.pdf`.

- [70-dimensionality-pca.md](/examples/transf/dimensionality/70-dimensionality-pca.md) - `dt_pca`: principal component analysis for projection and compression.
- [71-curvature-minimum.md](/examples/transf/dimensionality/71-curvature-minimum.md) - `fit_curvature_min`: detect minimum curvature for increasing curves.
- [72-curvature-maximum.md](/examples/transf/dimensionality/72-curvature-maximum.md) - `fit_curvature_max`: detect maximum curvature for decreasing curves.
