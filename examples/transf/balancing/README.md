# Balancing Examples

These examples correct class imbalance after the earlier variable transformations are already defined.

> Slide deck: [d037_transf_balancing.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d037_transf_balancing.pdf).

- [50-balancing-oversampling.md](/examples/transf/balancing/50-balancing-oversampling.md) - `bal_oversampling`: oversampling by replication or local SMOTE.
- [51-balancing-subsampling.md](/examples/transf/balancing/51-balancing-subsampling.md) - `bal_subsampling`: undersampling to reduce majority-class dominance.
