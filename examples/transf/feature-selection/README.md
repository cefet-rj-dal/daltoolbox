# Feature Selection Examples

These examples reduce the predictor set according to relevance, sparsity, or subset search.

> Slide deck: [d038-transf-feature-selection.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d038-transf-feature-selection.pdf).

- [60-feature-selection-information-gain.md](/examples/transf/feature-selection/60-feature-selection-information-gain.md) - `feature_selection_info_gain`: rank predictors by information gain.
- [61-feature-selection-relief.md](/examples/transf/feature-selection/61-feature-selection-relief.md) - `feature_selection_relief`: rank predictors through nearest-hit and nearest-miss contrasts.
- [62-feature-selection-stepwise.md](/examples/transf/feature-selection/62-feature-selection-stepwise.md) - `feature_selection_stepwise`: GLM-based stepwise selection.
- [63-feature-selection-lasso.md](/examples/transf/feature-selection/63-feature-selection-lasso.md) - `feature_selection_lasso`: L1-based embedded feature selection.
- [64-feature-selection-fss.md](/examples/transf/feature-selection/64-feature-selection-fss.md) - `feature_selection_fss`: forward subset search.
