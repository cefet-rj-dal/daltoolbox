# Encoding Examples

These examples change the representation of attributes so downstream learners can consume categorical inputs safely.

> Slide deck: [d035_transf_encoding.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d035_transf_encoding.pdf).

- [30-encoding-categorical-mapping.md](/examples/transf/encoding/30-encoding-categorical-mapping.md) - `categ_mapping`: one-hot encoding for categorical variables.
- [31-encoding-hierarchy-cut.md](/examples/transf/encoding/31-encoding-hierarchy-cut.md) - `hierarchy_cut`: create ordered categories from numeric cut points.
- [32-feature-generation.md](/examples/transf/encoding/32-feature-generation.md) - `feature_generation`: derive new attributes from existing ones.
