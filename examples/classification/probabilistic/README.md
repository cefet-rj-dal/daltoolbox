# Probabilistic Classifiers Examples

Classifiers that model the probability distribution of the data to infer the most likely class.

> Slide deck: [d044_classification_probabilistic.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d044_classification_probabilistic.pdf) already frames itself as "Model Families -- Probabilistic Classifiers" but only covers Naive Bayes (11). It does not yet cover multinomial logistic regression (19) — content to merge in is drafted as `d044_classification_probabilistic_ADDENDUM.md`.

- [11-probabilistic-naive-bayes.md](/examples/classification/probabilistic/11-probabilistic-naive-bayes.md) - `cla_nb`: probabilistic classifier based on conditional independence assumptions.
- [19-probabilistic-multinomial.md](/examples/classification/probabilistic/19-probabilistic-multinomial.md) - `cla_multinom`: multinomial logistic regression for multiclass problems.
