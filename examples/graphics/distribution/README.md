# Distribution, Relationship, Time-Series, and Export Examples

These plots cover four analytical questions in sequence: the shape of a single variable's distribution, the relationship between variables, ordered/temporal views, and how to export the final chart.

> Slide deck: [d072_graphics_distribution.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d072_graphics_distribution.pdf). Despite its filename, this deck already bundles four themes (Distribution Analysis, Relationships Between Variables, Time-Oriented Views, and Export and Delivery) in one presentation — kept as a single folder here to stay 1:1 with the deck as it exists today. If `d072` is ever split into separate decks, this folder should be split to match (into `distribution/`, `relationship/`, `time-series/`, and `export/`).

## Distribution Analysis

- [10-distribution-histogram.md](/examples/graphics/distribution/10-distribution-histogram.md) - histogram for binned frequency inspection.
- [11-distribution-density.md](/examples/graphics/distribution/11-distribution-density.md) - kernel density curve for smoothed distribution shapes.
- [12-distribution-boxplot.md](/examples/graphics/distribution/12-distribution-boxplot.md) - boxplot for quartiles, spread, and outliers.
- [13-distribution-boxplot-by-class.md](/examples/graphics/distribution/13-distribution-boxplot-by-class.md) - grouped boxplots for class-wise distribution comparison.
- [14-distribution-density-by-class.md](/examples/graphics/distribution/14-distribution-density-by-class.md) - grouped density curves for overlap and separation inspection.

## Relationships Between Variables

- [20-relationship-scatter.md](/examples/graphics/distribution/20-relationship-scatter.md) - scatter plot for two numeric variables.
- [21-relationship-points.md](/examples/graphics/distribution/21-relationship-points.md) - point plot for discrete or index-based observations without connecting lines.
- [22-relationship-correlation.md](/examples/graphics/distribution/22-relationship-correlation.md) - correlation heatmap for compact association inspection.
- [23-relationship-pair.md](/examples/graphics/distribution/23-relationship-pair.md) - scatter matrix for several numeric variables.
- [24-relationship-pair-advanced.md](/examples/graphics/distribution/24-relationship-pair-advanced.md) - scatter matrix with explicit class palette control.
- [25-relationship-parallel.md](/examples/graphics/distribution/25-relationship-parallel.md) - parallel coordinates for multivariate profile comparison.
- [26-relationship-pixel.md](/examples/graphics/distribution/26-relationship-pixel.md) - pixel-oriented matrix visualization.
- [27-relationship-dendrogram.md](/examples/graphics/distribution/27-relationship-dendrogram.md) - dendrogram view of hierarchical structure.

## Time-Oriented Views

- [30-time-series-lines.md](/examples/graphics/distribution/30-time-series-lines.md) - multi-line view for ordered series.
- [31-time-series-basic.md](/examples/graphics/distribution/31-time-series-basic.md) - simple exploratory time-series display.
- [32-time-series-forecast.md](/examples/graphics/distribution/32-time-series-forecast.md) - observed series with fit and forecast horizon.

## Export and Delivery

- [40-export-save-pdf.md](/examples/graphics/distribution/40-export-save-pdf.md) - export charts to PDF with controlled dimensions.
- [41-export-save-jpg.md](/examples/graphics/distribution/41-export-save-jpg.md) - export charts to raster formats such as JPG.
