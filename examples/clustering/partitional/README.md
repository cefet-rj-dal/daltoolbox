# Partition-Based Foundations Examples

These examples are the fastest way to understand how `daltoolbox` represents unsupervised learners, cluster assignments, and evaluation outputs.

- [01-partitional-kmeans.md](/examples/clustering/partitional/01-partitional-kmeans.md) - `clu_kmeans`: centroid-based clustering with Euclidean partitions.
- [02-medoid-pam.md](/examples/clustering/partitional/02-medoid-pam.md) - `clu_pam`: medoid-based clustering, often more robust to extreme points.
