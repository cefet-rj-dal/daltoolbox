# Clustering Examples

This section organizes clustering by modeling family, one subfolder per family, so each folder maps 1:1 to a slide deck.

A good reading order is to start with centroid-based clustering, compare it with medoid-based clustering, then move to density-based discovery, then to the soft/model-based/hierarchical views, and only after that inspect clustering model selection.

- [Partition-Based Foundations](partitional/README.md) - [d061-clustering-partitional.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d061-clustering-partitional.pdf)
- [Density-Based Clustering](density/README.md) - [d062-clustering-density.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d062-clustering-density.pdf)
- [Soft, Model-Based, and Hierarchical Views](advanced-views/README.md) - [d063-clustering-advanced-views.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d063-clustering-advanced-views.pdf) (draft)
