# Clustering Examples

This section organizes clustering by modeling family, one subfolder per family, so each folder maps 1:1 to a slide deck.

A good reading order is to start with centroid-based clustering, compare it with medoid-based clustering, then move to density-based discovery, then to the soft/model-based/hierarchical views, and only after that inspect clustering model selection.

- [Partition-Based Foundations](partitional/README.Rmd) - [d061_clustering_partitional.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d061_clustering_partitional.pdf)
- [Density-Based Clustering](density/README.Rmd) - [d062_clustering_density.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d062_clustering_density.pdf)
- [Soft, Model-Based, and Hierarchical Views](advanced-views/README.Rmd) - [d063_clustering_advanced-views.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d063_clustering_advanced-views.pdf) (draft)
- [Model Selection](model-selection/README.Rmd) - [d064_clustering_model-selection.pdf](https://github.com/cefet-rj-dal/daltoolbox/blob/main/examples/pdf/d064_clustering_model-selection.pdf) (draft)
