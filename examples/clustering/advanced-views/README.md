# Soft, Model-Based, and Hierarchical Views Examples

This block widens the clustering perspective beyond hard partitions: memberships, probabilistic mixtures, hierarchical merge structure, and graph communities.

- [11-fuzzy-cmeans.md](/examples/clustering/advanced-views/11-fuzzy-cmeans.md) - `cluster_cmeans`: fuzzy clustering with membership degrees.
- [12-model-based-gmm.md](/examples/clustering/advanced-views/12-model-based-gmm.md) - `cluster_gmm`: Gaussian mixture model clustering.
- [13-hierarchical-hclust.md](/examples/clustering/advanced-views/13-hierarchical-hclust.md) - `cluster_hclust`: agglomerative hierarchical clustering.
- [14-graph-louvain.md](/examples/clustering/advanced-views/14-graph-louvain.md) - `cluster_louvain_graph`: graph community detection by modularity optimization.
